# Kinetic Atelier - Native Web Components

This project is a high-performance fitness dashboard converted from React to Native Web Components.

## Tech Stack
- **Native Web Components**: No UI libraries (like Lit/React).
- **Vite**: Build tool and dev server.
- **Tailwind CSS v4**: Styling.
- **Vitest**: Unit testing.
- **Playwright**: E2E testing.
- **D3.js**: Data visualization.
- **Lucide**: Iconography.

## Getting Started
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Build for production: `npm run build`

## Testing
- Run unit tests: `npm test`
- Run E2E tests: `npm run test:e2e`

## Project Structure
- `src/core`: Base classes and core logic.
- `src/router`: Routing implementation.
- `src/components`: Reusable UI components (Layout, etc.).
- `src/views`: Main page views.
